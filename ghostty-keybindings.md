# Ghostty Keybindings

| Keybinding       | Action            |
|------------------|-------------------|
| Cmd + S + R      | Reload Config     |
| Cmd + S + X      | Close Surface     |
| Cmd + S + N      | New Window        |
| Cmd + S + C      | New Tab           |
| Cmd + S + Shift + L | Next Tab      |
| Cmd + S + Shift + H | Previous Tab  |
| Cmd + S + ,      | Move Tab Left     |
| Cmd + S + .      | Move Tab Right    |
| Cmd + S + 1      | Go to Tab 1       |
| Cmd + S + 2      | Go to Tab 2       |
| Cmd + S + 3      | Go to Tab 3       |
| Cmd + S + 4      | Go to Tab 4       |
| Cmd + S + 5      | Go to Tab 5       |
| Cmd + S + 6      | Go to Tab 6       |
| Cmd + S + 7      | Go to Tab 7       |
| Cmd + S + 8      | Go to Tab 8       |
| Cmd + S + 9      | Go to Tab 9       |

| Pane Mgmt        |   					|
| Cmd + S + \\     | New Pane (Vert) |
| Cmd + S + -      | New Pane (Horiz)  |
| Cmd + S + J      | Go to Pane (Bottom) |
| Cmd + S + K      | Go to Pane (Top) |
| Cmd + S + H      | Go to Pane (Left) |
| Cmd + S + L      | Go to Pane (Right) |
| Cmd + S + Z      | Toggle Pane Zoom |
| Cmd + S + E      | Equalize Splits   |
